# TravelMap

A shared US travel map for two people. Click a state to mark it visited,
switch "Record for" to say which of you the edit is for, and drop labelled
pins for specific trips. See both of your progress side by side, or filter
to just one person.

There is no login: anyone who can reach this app's Home Assistant Ingress
panel can view and edit both profiles. That's an intentional, explicit
choice for a two-person household app - see `DOCS.md` for details and the
"is this OK for your setup" note.
